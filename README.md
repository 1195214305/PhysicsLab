# PhysicsLab - 高中物理虚拟实验室

基于阿里云 ESA Pages 边缘计算平台构建的高中物理虚拟实验室，涵盖人教版高中物理教材中的核心实验，通过交互式模拟帮助学生深入理解物理原理。

> 本项目由 [阿里云ESA](https://www.aliyun.com/product/esa) 提供加速、计算和保护

![Alibaba Cloud ESA](https://img.alicdn.com/imgextra/i3/O1CN01H1UU3i1Cti9lYtFrs_!!6000000000139-2-tps-7534-844.png)

## 项目介绍

### 创意性

PhysicsLab 将传统物理实验搬到云端，通过精心设计的交互式模拟，让学生能够：
- 突破时空限制，随时随地进行物理实验
- 自由调整实验参数，观察不同条件下的物理现象
- 通过可视化图表直观理解抽象的物理规律
- 借助 AI 辅导获得个性化的学习指导

### 实用性

- **教学辅助**：教师可在课堂演示实验，学生可在家预习复习
- **安全无忧**：无需真实器材，避免实验安全隐患
- **数据分析**：自动记录实验数据，支持导出实验报告
- **移动优先**：完美适配手机端，随时随地学习

### 技术深度

- 21 个物理实验的完整模拟，涵盖力学、电磁学、光学、热学、近代物理五大领域
- 基于物理引擎的精确计算，确保模拟结果符合真实物理规律
- 利用阿里云 ESA 边缘计算实现毫秒级响应
- 集成通义千问 AI 提供智能物理辅导

## How we use Edge

PhysicsLab 充分利用阿里云 ESA 边缘计算能力，实现了以下核心功能：

### 1. 边缘静态资源加速

前端应用部署在 ESA Pages 上，利用全球边缘节点实现：
- 静态资源（HTML/CSS/JS/图片）就近分发
- 首屏加载时间 < 1秒
- 全球用户访问延迟 < 50ms

### 2. 边缘函数 - AI 物理辅导

```
/functions/ai/tutor.ts
```

AI 辅导功能通过边缘函数实现，相比传统云函数的优势：
- **低延迟**：边缘节点就近处理请求，减少网络往返时间
- **高可用**：多节点部署，自动故障转移
- **成本优化**：按需执行，无需维护服务器

边缘函数调用通义千问 API，为学生提供：
- 实验原理解答
- 公式推导指导
- 实验操作建议
- 错误分析帮助

### 3. 边缘计算的不可替代性

| 场景 | 传统方案 | ESA 边缘方案 | 优势 |
|------|----------|--------------|------|
| 静态资源 | 单点服务器 | 全球边缘节点 | 延迟降低 80% |
| AI 接口 | 中心化云函数 | 边缘函数 | 响应时间减少 60% |
| 用户体验 | 加载缓慢 | 秒开体验 | 用户留存提升 |

对于物理实验模拟这类需要实时交互的应用，边缘计算带来的低延迟体验是不可替代的。学生在调整参数时能够立即看到模拟结果的变化，这种即时反馈对于理解物理规律至关重要。

## 快速开始

### 环境要求

- Node.js 18+
- npm 或 yarn

### 本地开发

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

### 部署到 ESA Pages

1. 将代码推送到 GitHub 仓库
2. 在阿里云 ESA Pages 控制台导入项目
3. 配置构建命令：
   - 构建命令：`cd frontend && npm install && npm run build`
   - 输出目录：`frontend/dist`
4. 配置环境变量（如需 AI 功能）：
   - `QWEN_API_KEY`: 通义千问 API 密钥
